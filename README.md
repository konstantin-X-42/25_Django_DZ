# Django-проект: Онлайн-каталог товаров и Блог оповещения <img width="137" height="41" alt="Skypro" src="https://github.com/user-attachments/assets/ac708293-d4d3-4222-980d-a89643052ae0" />

Веб-проект на базе фреймворка **Django**, реализующий динамическую структуру интернет-магазина-каталога с интегрированным новостным блогом, поддерживающим полный цикл CRUD-операций. Архитектура построена на базе классов (CBV), ORM-моделей, валидных HTML-форм, единой системы наследования шаблонов, менеджера окружения `mailers` и СУБД PostgreSQL.

## 🛠 Выполненные задачи (Критерии проверки)

### 1. Рефакторинг и оптимизация контроллеров на CBV
* **Перевод на классы:** Все существовавшие FBV-контроллеры приложения `catalog` (включая главную страницу, категории, заказы, детальный просмотр, страницу контактов с обработкой POST-форм и создание продуктов) полностью переписаны на высокоуровневые **Class-Based Views** (`ListView`, `DetailView`, `TemplateView`, `CreateView`).
* **Сохранение логики:** В классах полностью воссоздана кастомная бизнес-логика (выводы в консоль первых 5 продуктов для отладки, динамическое извлечение контактных данных организации `ContactInfo`).
* **Метод `.as_view()`:** Все маршруты в файле `catalog/urls.py` переведены на вызовы классов с сохранением исходных имен путей (`name`), исключая конфликты в шаблонах.

### 2. Разработка изолированного приложения Блога
* **Архитектурный модуль:** Создано и зарегистрировано в `settings.py` новое Django-приложение `blog`.
* **ORM-модель данных:** Реализована модель `BlogEntry` с автоматическим полем даты создания (`DateTimeField(auto_now_add=True)`), флагом публикации, счетчиком просмотров и строковым методом `__str__`. Настроена мета-информация класса для корректного отображения в панели администратора на русском языке.
* **База данных:** Созданы и успешно применены новые файлы миграций для интеграции таблиц блога в PostgreSQL.

### 3. Реализация CRUD-функционала и умных счетчиков в блоге
* **Полный CRUD:** На базе CBV реализован полный цикл управления записями по префиксу `blogs/` через контекстные URL (заканчивающиеся на слэш `/` согласно ТЗ):
  * `BlogEntryListView` — Вывод списка опубликованных статей (настроена фильтрация `get_queryset`).
  * `BlogEntryDetailView` — Детальный просмотр статьи с динамическим инкрементом просмотров.
  * `BlogEntryCreateView` — Форма создания новой записи.
  * `BlogEntryUpdateView` — Редактирование статьи с динамическим редиректом (`get_success_url`) на страницу обновленной записи.
  * `BlogEntryDeleteView` — Удаление статьи с возвратом на список.
* **Счетчик просмотров:** Переопределен метод `get_object` в детальном контроллере блога: при каждом успешном открытии статьи счетчик `views_count` инкрементируется на 1 и сохраняется в БД.

### 4. Автоматическое почтовое уведомление (Доп. задание со звездочкой)
* Внедрена отправка электронных писем с использованием современного пакетного менеджера почты Django **`mailers`**.
* Добавлена логика автоматического триггера: когда счетчик просмотров статьи `views_count` достигает ровно **100 просмотров**, система автоматически формирует и генерирует поздравительное письмо на адрес администратора, указанный в скрытых переменных окружения.

### 5. Безопасность и архитектура окружения
* Личные контактные данные администратора (`ADMIN_EMAIL`) вынесены в изолированный файл `.env` для предотвращения компрометации данных в публичных Git-репозиториях.
* Все URL-маршруты приложений вынесены в локальные файлы `urls.py` и подключены в главном конфигурационном узле `config/urls.py` через метод `include` с использованием пространств имен (`namespace`).

## 🚀 Инструкция по запуску проекта

### 1. Клонирование репозитория и переход в рабочую ветку
```bash
git clone <ссылка_на_твой_репозиторий>
cd 25_Django_DZ
git checkout feature/homework-2
```

### 2. Настройка файлов окружения
Создайте в корневой директории проекта файл **`.env`** на основе шаблона `.env.sample`. Обязательно добавьте новые переменные для почты:
```env
SECRET_KEY=django-insecure-your-actual-secret-key
DEBUG=True

DB_NAME=имя_вашей_базы_данных_в_postgres
DB_USER=имя_пользователя_postgres
DB_PASSWORD=ваш_пароль_от_postgres
DB_HOST=localhost
DB_PORT=5432

# Настройки почты для задания со звездочкой
ADMIN_EMAIL=kostyaniqy@yandex.ru
EMAIL_HOST_USER=kostyaniqy@yandex.ru
EMAIL_HOST_PASSWORD=твой_16_значный_пароль_приложения_яндекс
```

### 3. Установка зависимостей и активация окружения через Poetry
```bash
poetry install
poetry shell
```

### 4. Применение миграций (включая каталог и блог)
```bash
python manage.py migrate
```

### 5. Создание администратора и запуск локального веб-сервера
```bash
python manage.py createsuperuser
python manage.py runserver
```
* Главная страница каталога товаров: [http://127.0.0](http://127.0.0)
* Главная страница списка статей блога: [http://127.0.0blogs/](http://127.0.0blogs/)
* Административная панель Django: [http://127.0.0admin/](http://127.0.0admin/)
