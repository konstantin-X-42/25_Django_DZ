# Django-проект: Онлайн-каталог товаров <img width="137" height="41" alt="Skypro" src="https://github.com/user-attachments/assets/ac708293-d4d3-4222-980d-a89643052ae0" />

Учебный веб-проект на базе фреймворка **Django**, реализующий динамическую структуру многостраничного сайта-каталога интернет-магазина с интеграцией ORM-моделей, валидных HTML-форм, единой системы наследования шаблонов и СУБД PostgreSQL.

## 🛠 Выполненные задачи (Критерии проверки)

### 1. Реализация динамической маршрутизации и детальной страницы товара
* Настроен маршрут детального просмотра товара вида `/products/<int:pk>/` с обязательным использованием имени пути `product_detail`.
* Реализован FBV-контроллер `product_detail_view` с безопасным извлечением объектов из базы данных через ORM-метод `get_object_or_404(Product, pk=pk)`.
* Создан отдельный HTML-шаблон `product_detail.html` для вывода полной информации о продукте (наименование, описание, категория, цена, изображение) и кнопкой быстрого возврата на главную страницу.

### 2. Оптимизация каталога товаров на главной странице
* Запрос в контроллере главной страницы переведён на лаконичный ORM-вызов всех записей: `Product.objects.all()`.
* Внедрена итерация элементов в шаблоне с помощью тега `{% for %}` для автоматической генерации карточек товаров.
* Реализована обрезка текстового описания продуктов до **100 символов** с помощью встроенного шаблонного фильтра `{{ product.description|truncatechars:100 }}` для сохранения адаптивности интерфейса.

### 3. Единая архитектура и наследование HTML-шаблонов
* Сформирован главный базовый шаблон `base.html`, содержащий общие стили и структуру сайта.
* Боковая панель навигации (меню) успешно вынесена в изолированный подшаблон `menu.html` внутри папки `includes/` и интегрирована во все разделы с помощью тега `{% include %}`.
* Все основные страницы (`home.html`, `contacts.html`, `product_detail.html`, `product_form.html`) переведены на строгое наследование через тег `{% extends %}`, что полностью предотвращает дублирование кода и сохраняет целостность меню при переходах.

### 4. Интеграция Django-форм и безопасность ввода данных (Доп. задание)
* Разработан выделенный файл **`catalog/forms.py`** и класс формы `ProductForm` на базе `forms.ModelForm` для безопасного добавления товаров.
* Внедрен метод `__init__` для автоматического наложения единых CSS/инлайн-стилей на все поля ввода.
* Настроен контроллер `create_product_view` для обработки POST-запросов, проверки валидности данных формой (`form.is_valid()`), защиты от ошибок и последующего сохранения объектов в СУБД.
* Создан шаблон `product_form.html` с выводом полей формы через `{{ form.as_p }}` и защитой от межсайтовой подделки запросов (`{% csrf_token %}`).

### 5. Архитектурная подготовка (База данных, Git, Окружение)
* Настроен и вычищен файл `.gitignore` (исключены папки `.venv`, `.env`, файлы кэша `__pycache__`).
* Разработка велась в изолированной Git-ветке `feature/homework-1` с последующим слиянием в `develop`.
* Зависимости проекта зафиксированы в конфигурационных файлах менеджера пакетов **Poetry** (`pyproject.toml`, `poetry.lock`).

## 🚀 Инструкция по запуску проекта

### 1. Клонирование репозитория и переход в ветку
```bash
git clone <ссылка_на_твой_репозиторий>
cd 23_Django_DZ
git checkout feature/homework-1
```

### 2. Настройка файлов окружения
Создайте в корневой директории проекта файл **`.env`** на основе шаблона `.env.sample` и заполните его локальными параметрами доступа к PostgreSQL:
```env
SECRET_KEY=django-insecure-your-actual-secret-key
DEBUG=True

DB_NAME=имя_вашей_базы_данных_в_postgres
DB_USER=имя_пользователя_postgres
DB_PASSWORD=ваш_пароль_от_postgres
DB_HOST=localhost
DB_PORT=5432
```

### 3. Установка зависимостей и активация окружения через Poetry
```bash
poetry install
poetry shell
```

### 4. Применение миграций и наполнение базы
```bash
python manage.py migrate
python manage.py fill
```

### 5. Создание администратора и запуск
```bash
python manage.py createsuperuser
python manage.py runserver
```
* Главная страница каталога: [http://127.0.0](http://127.0.0)
* Страница создания товара: [http://127.0.0products/create/](http://127.0.0products/create/)
* Административная панель: [http://127.0.0admin/](http://127.0.0admin/)
